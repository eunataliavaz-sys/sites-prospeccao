Como conectar o Claude ao seu Instagram

O caminho que eu uso para publicar pela API oficial da Meta, sem app de agendamento.

01Conta profissional

Seu Instagram precisa ser conta profissional (Criador ou Empresa).

02Crie o app na Meta

É de graça e leva uns 15 minutos. Os nomes dos botões podem mudar um pouco, porque a Meta atualiza o painel com frequência.

  1. Entre em developers.facebook.com com o seu Facebook e clique em Começar para criar a sua conta de desenvolvedor. A Meta confirma por SMS ou e-mail.
  2. Vá em Meus apps e clique em Criar app. Dê um nome, por exemplo "Publicador do meu Instagram".
  3. No caso de uso, escolha a opção de gerenciar mensagens e conteúdo do Instagram. Se pedir um portfólio empresarial, escolha o seu ou siga sem.
  4. No painel do app, abra Configuração da API com login do Instagram (em inglês, API setup with Instagram login).
  5. Em Gerar tokens de acesso, clique em Adicionar conta, entre com o Instagram que vai publicar e autorize as permissões.
  6. Clique em Gerar token. Copie e salve num arquivo de texto no seu computador. Anote também o ID da conta que aparece ao lado.

Para publicar só na sua própria conta, não precisa enviar o app para análise da Meta.

03Travou? Peça ajuda ao Claude

Cole este pedido no Claude (funciona no plano gratuito). Ele te guia tela por tela e você pode mandar print do que aparecer, tampando o token.

Estou criando um app na Meta (developers.facebook.com) para publicar no meu Instagram pela API oficial, com login do Instagram. Me guie um passo por vez: diga exatamente onde clicar, espere eu contar o que apareceu na tela e só então passe para o próximo passo. Se eu mandar um print, use para me orientar. Nunca me peça para colar o token na conversa.

04Peça o script ao Claude Code

Este passo usa o Claude Code, que faz parte dos planos pagos do Claude (a partir do Pro). Cole este pedido nele:

Crie um script em Python que publique um carrossel no meu Instagram pela API oficial da Meta (Graph API), a partir de imagens com link público e de uma legenda em arquivo. Leia o token de um arquivo fora desta pasta e nunca mostre o token na tela. Antes de publicar, mostre o que vai sair e peça a minha confirmação.

05Cuidado com o token

O token é a chave da sua conta. Guarde fora de pastas compartilhadas e nunca cole em conversa nem em post.

Nada sai sem a sua aprovação: o script mostra o post e espera o seu ok.
